## 全局变量和局部变量

+ 声明适用的程序的范围被称为声明的作用域。在一个过程中，如果名字在过程的声明之内，它的出现即为过程的局部变量；否则，出现即为非局部变量。

+ 全局变量除非被删除，否则将存活到程序运行结束。局部变量随着存放的栈一起释放。

## 闭包

在内部函数里，对外部作用域（但不是全局作用域）的变量进行引用，那么内部函数就被认为是闭包。定义在外部函数内但是有内部函数引用的变量称为自由变量。

闭包的例子

```python
def counter(start_at=0):
    count = [start_at]
    def incr():
        count[0] += 1
        return count[0]
    return incr

c = counter(5)
print(c())
print(c())
print(c())
print(c())
>> 6
>> 7
>> 8
>> 9
```

闭包更适合需要一个必需有自己的作用域的回调函数的情况。
