python内存管理基于私有堆，所有对象都存储于其中。代码通过引用访问堆。

1. 内存分配机制：使用内存池保存小块内存（例如整数、短字符串），避免频繁调用系统malloc、free，提升效率；大块内存通过C标准库的malloc和free分配

2. 对象特定分配器：对于常用的对象（列表、字典）有专门的内存分配器，进一步优化性能。

3. 内存碎片管理：将内存分为大小不同的块（8,16,32字节），按需分配。

4. 内存优化技术：小整数（-5到256）、短字符串会被驻留，重复使用时指向相同地址，或者调用sys.interal主动驻留；某些不可变对象（元祖）在复制时共享内存，直到被修改。

python的内存回收机制：

1. 引用计数

2. 标记清除：从根对象出发，遍历所有可达对象并标记为存活；遍历堆内存，回收未被标记的对象。

3. 分代回收 将对象分为三代，新创建的进入G0，每次存活都晋级到下一代。GC时优先扫描年轻代


对象的引用，函数调用关系保存在栈里；**注意：代码本身也是对象一种，所以保存在堆里**；模块的缓存会存储在sys.modules里面，其本身也是对象，因此存在于堆空间；


对于对象驻留，值得注意的是：只有在代码中写死的字符串会被驻留，而在运行时创建的对象并不会驻留，例如

```python
s3 = "hello world!"
sub1 = s3[0:5]        # 动态切片生成 "hello"（可能未被驻留）
sub2 = "hello"         # 直接字面量（自动驻留）

print(id(sub1), id(sub2))  # 不同值

```

需要注意运行时和编译优化时的概念

```python
s1 = "Py" "thon"     # 隐式拼接（无加号）
s2 = "Python"
print(s1 is s2)      # True（驻留）

a = "Py"
b = "thon"
s3 = a + b
s4 = "Python"
print(s3 is s4)      # False（未驻留）
```
